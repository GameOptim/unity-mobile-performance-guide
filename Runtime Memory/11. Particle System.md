# 2.11 Particle System

When analyzing GameOptim’s particle system curves together with the particle system resource list, we find that in many projects, the **total particle count in memory** is far higher than the **actual playing particle count**.

This appears in the curves as the **blue curve being much higher than the purple curve**, and in the resource list as many resources having a **peak count in memory far higher than the peak playing count**.

This indicates significant **cache waste** in particle system memory.

![41](https://uwa-ducument-img.oss-cn-beijing.aliyuncs.com/GameOptim/2.11Particle/41.png)

![42](https://uwa-ducument-img.oss-cn-beijing.aliyuncs.com/GameOptim/2.11Particle/42.png)

In this case:

1. Check for deprecated but undeleted particle systems during project iteration, or particle components used for testing but not unlinked. Even in **Deactivated** state, they are included in the package, loaded into the scene, and kept in memory.
2. Optimize the particle **caching strategy**, reduce unnecessary particle caching, and try to **cache only as many particles as needed for playback**.
